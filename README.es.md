# Portafolio de automatización con Python

[English](README.md) · **Español**

Proyectos de muestra hechos sobre webs creadas para practicar scraping. Cada carpeta tiene su README, el script, el resultado y una imagen de vista previa.

| Proyecto | Qué hace | Comprobado |
|---|---|---|
| [books-to-excel](books-to-excel/README.es.md) | Extrae 1.000 libros de 50 páginas a un Excel con formato | 1.000 de 1.000 filas, 0 campos vacíos |
| [price-alert-monitor](price-alert-monitor/README.es.md) | Vigila un catálogo y avisa por Telegram o Discord de productos nuevos y cambios de precio | Aviso real recibido en Telegram |
| [pdf-tables-to-excel](pdf-tables-to-excel/README.es.md) | Junta las tablas de un PDF de varias páginas en una sola hoja de Excel limpia | 150 de 150 filas idénticas al original |

Hecho con ayuda de IA (Claude). Cada resultado se comprueba contra su fuente; las comprobaciones están en la tabla de arriba.

Cualquiera se ejecuta con:

```
pip install -r requirements.txt
python <script>.py
```
