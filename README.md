# Python automation portfolio

**English** · [Español](README.es.md)

Sample projects built on websites made for scraping practice. Each folder has its own README, the script, the result and a preview image.

| Project | What it does | Checked |
|---|---|---|
| [books-to-excel](books-to-excel/) | Scrapes 1,000 books across 50 pages into a formatted Excel file | 1,000 of 1,000 rows, 0 empty fields |
| [price-alert-monitor](price-alert-monitor/) | Watches a catalogue and sends Telegram or Discord alerts for new products and price changes | Real Telegram alert received |
| [pdf-tables-to-excel](pdf-tables-to-excel/) | Joins the tables of a multi-page PDF into one clean Excel sheet | 150 of 150 rows identical to the source |

Built with AI assistance (Claude). Every result is checked against its source; the checks are listed in the table above.

Run any of them with:

```
pip install -r requirements.txt
python <script>.py
```
